# Security Policy

## Supported Versions

Only the latest version of `dart_lz4` published on [pub.dev](https://pub.dev/packages/dart_lz4) is supported.

## Reporting a Vulnerability

Please report security issues via GitHub Security Advisories:

- <https://github.com/jxoesneon/dart_lz4/security/advisories>

If you are unable to use GitHub advisories, please contact the maintainers directly.

## Vulnerability Response Process

- **Acknowledgement:** We will acknowledge receipt of a report within 48 hours.
- **Verification:** We will verify the report and determine the impact.
- **Fix:** We will develop a fix and perform regression testing.
- **Disclosure:** We will coordinate a disclosure date with the reporter.
- **Publication:** We will publish the fix and a security advisory.

## Security Practices

- **Fuzzing:** We perform continuous fuzz testing via GitHub Actions.
- **SAST:** We use GitHub CodeQL for static analysis.
- **Dependency Monitoring:** We use Dependabot for automated dependency updates.
- **Supply Chain:** We use OSSF Scorecard and OIDC publishing for verified releases.
