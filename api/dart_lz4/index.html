dart_lz4 library

Pure Dart LZ4 and LZ4HC APIs.

This library provides:

  • LZ4 block compression/decompression.
  • LZ4 frame encode/decode (including skippable frames).
  • Streaming frame encode/decode as StreamTransformers.

All APIs are Uint8List-based and are intended to work on all Dart platforms, including Web.
