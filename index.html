dart_lz4

The reference standard for ultra-fast, zero-allocation LZ4 compression in pure Dart.

Get StartedAPI Reference

Guarded Wildcopy

Optimized 8-byte chunk copying with a fast 32-bit fallback for Web environments. Enjoy native-like decompression speeds without sacrificing bounds safety or Web compatibility.

Polymorphic Engine

Zero-allocation architecture designed to squeeze maximum performance out of the Dart VM (JIT/AOT). Extremely low garbage collection pressure for high-throughput streaming.

Reference Standard

100% compliant with the official LZ4 block and frame specifications, including LZ4HC, skippable frames, legacy formats, and dictionary compression.
